## ترتیب پیشنهادی بستن سرنخ‌ها
1. حساب کاربری، هویت آنلاین، پروفایل و تنظیمات حساب (استخراج الگوی موجود آنلاین کافه؛ شماره تلفن + PIN برای کاربر، ورود مدیر جداگانه).
2. پیام دوطرفه و صندوق ورودی مدیریت.
3. سوابق سفارش/اشتراک و اتصال یکپارچه به حساب.
4. داشبورد مدیریت، فروشگاه، سفارش، اشتراک، پرداخت و تخفیف؛ تست انتها‌به‌انتها.
5. مدیریت محتوا، مودال‌ها، ظاهر و هویت بصری؛ تست واقعی آپلود و ذخیره.
6. امنیت، کنترل‌های فنی، کارایی، تست موبایل/دسکتاپ و آمادگی انتشار.
